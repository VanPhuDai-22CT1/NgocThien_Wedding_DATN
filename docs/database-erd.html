Prisma Schema - Thiết kế Database

Bản trực quan dựa trên các Sequelize model hiện có của dự án Ngọc Thiện Wedding. Có thể dùng trong báo cáo như sơ đồ ERD/Prisma schema.

Người dùng Dịch vụ / Sản phẩm Đơn hàng Hệ thống

Người dùng

users User

  • idInt PK
  • usernameString unique
  • emailString unique
  • passwordString
  • full_nameString?
  • phoneString?
  • addressText?
  • avatarString?
  • roleuser | admin
  • is_activeBoolean

consultations Consultation

  • idInt PK
  • user_idInt? FK
  • nameString
  • emailString
  • phoneString
  • serviceText?
  • event_dateDateTime?
  • statusEnum
  • is_readBoolean

Dịch vụ

products Product

  • idInt PK
  • nameString
  • descriptionText?
  • priceBigInt
  • stockInt
  • category_idInt?
  • image_urlsJson
  • coverString?
  • is_featuredBoolean
  • service_detailsText?

product_reviews ProductReview

  • idInt PK
  • product_idInt FK
  • user_idInt? FK
  • reviewer_nameString
  • ratingInt
  • commentText?

Đơn hàng

orders Order

  • idInt PK
  • user_idInt FK
  • order_codeString unique
  • total_amountBigInt
  • statusOrderStatus
  • delivery_addressText?
  • phoneString?
  • payment_methodString?
  • payment_statusPaymentStatus

order_items OrderItem

  • idInt PK
  • order_idInt FK
  • product_idInt FK
  • quantityInt
  • priceBigInt
  • subtotalBigInt

shopping_carts ShoppingCart

  • idInt PK
  • user_idInt FK
  • product_idInt FK
  • quantityInt
  • uniqueuser + product

Hệ thống

live_chat_sessions LiveChatSession

  • idInt PK
  • chat_sessionString unique
  • customer_nameString
  • customer_emailString?
  • user_idInt? FK
  • statusactive | closed
  • is_read_by_adminBoolean

live_chat_messages LiveChatMessage

  • idInt PK
  • chat_sessionString FK
  • sender_typecustomer | admin
  • sender_nameString
  • messageText

homepage_configs HomepageConfig

  • idInt PK
  • gallery_imagesJson
  • header_slider_imagesJson
  • hero_background_imageString?
  • consult_imageString?
  • image_historyJson

Quan hệ chính

User 1 - n Order qua orders.user_id
Order 1 - n OrderItem qua order_items.order_id
Product 1 - n OrderItem qua order_items.product_id
User 1 - n ShoppingCart qua shopping_carts.user_id
Product 1 - n ShoppingCart qua shopping_carts.product_id
Product 1 - n ProductReview qua product_reviews.product_id
User 1 - n Consultation qua consultations.user_id
LiveChatSession 1 - n LiveChatMessage qua chat_session
User 1 - n LiveChatSession qua live_chat_sessions.user_id
